:: About Apukäsi ::

Apukäsi is an AI agent CLI designed to help you, not replace you. It supports OpenAI-compatible API endpoints and provides a practical, safe, and lightweight experience for developers who value control over their workflow.

Why Apukäsi? It prioritizes trust over autonomy. Before creating, modifying, or deleting files, it will always ask for your permission. The goal is to assist your workflow without making destructive changes you didn't approve.

Built entirely in Python, Apukäsi is fast, minimal, and easy to customize. It includes 50 themes (with more to come) including ~17 LGBTQ+ themes.

:: Features ::

★ Chat Mode

Conversations, debugging, and coding assistance at your fingertips.

★ Build Mode

Implement and modify projects with guided AI assistance.

★ Plan Mode

Turn ideas into structured development plans before writing code.

★ Permission-based Editing

You approve every file change. No surprises, no surprises.

★ OpenAI-Compatible

Works with OpenRouter, local models, OmniRoute, and more.

★ 50+ Themes

~17 LGBTQ+ themes included. Make it yours.

:: Compatibility ::

Apukäsi is compatible with any OpenAI-compatible API. Works with:

  • OpenRouter - Access multiple models through one API
  • Local models - Run privately on your own hardware
  • OmniRoute - Seamless API routing
  • And more... - Any OpenAI-compatible endpoint

:: Open Source ::

Apukäsi is free and community-driven. If you discover a bug, have a feature request, or want to contribute, feel free to open an issue or submit a pull request.

Thank you for helping make Apukäsi better! Please do keep in mind that this is still a beta version and it may not be perfect.
